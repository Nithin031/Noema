PERSONAL BEHAVIORAL INTELLIGENCE · LOCAL-FIRST

Understand what you're doing. Compare it to what you meant.

Most productivity software can tell you where your time went. Noema is interested in a harder question: what was I actually doing, and was it what I intended to do?

A stream of windows, tabs, presence signals and heartbeats is not behavior by itself. Noema turns raw desktop telemetry into semantic activity episodes, compares them against stated intent, detects sustained drift, reasons about whether an intervention is appropriate, and measures whether it helped.

THE CENTRAL DISTINCTION

Noema keeps seven concepts separate

A window title is evidence, not a conclusion. Being productive is not the same as being aligned with the active goal. A displayed intervention is not a successful one. The system refuses to collapse these into a single score.

Insufficient evidence resolves to UNKNOWN rather than an invented verdict.

  1. 01 ACTIVITY raw telemetry
  2. 02 MEANING semantic episode
  3. 03 INTENT stated goal
  4. 04 ALIGNMENT aligned / misaligned / unknown
  5. 05 DRIFT sustained, not momentary
  6. 06 INTERVENTION policy-gated action
  7. 07 OUTCOME measured recovery

    MODEL ROUTING

    Classification is not intervention reasoning

    The two jobs run on separate tiers, and the provider layer rejects cross-tier substitution rather than silently spending quota from the wrong model class.

    CLASSIFICATION TIER

    1. Gemini 3.8 Flash
    2. Gemini 3.7 Flash
    3. Gemini 3.6 Flash

    Reserved for classifying episodes. Never used for meme selection, intervention copy, strategy or auxiliary enrichment.

    REASONING TIER

    1. Gemini 3.5 Flash
    2. Gemini 3.5 Flash Lite
    3. Gemini 3.1 Flash Lite
    4. Gemini 2.5 Flash

    Intervention reasoning, response strategy, severity, tone, meme intent and ranking, contextual copy.

    FAILURE IS A STATE

    RATE_LIMITED · TIMEOUT INVALID_OUTPUT · PROVIDER_ERROR UNAVAILABLE
    429 must not become
    NEUTRAL 40%

    A failed model call never becomes a semantic label. Sessions stay pending with retry state, and the UI shows an explicit unavailable state.

    HONESTY RULES

    Token counts are exact only when the provider reported them, otherwise labelled estimated or unknown — never zero-filled. P95/P99 require n≥5 samples. Unknown pricing is null, never $0.

    FULLY LOCAL OPTION

    Hosted inference is optional. Ollama runs the same contracts on-device.

    NOEMA_PROVIDER=ollama

    THE LOOP IS CLOSED

    An intervention that was displayed is not an intervention that worked

    Noema records what happened afterwards. Recovery means a later productive episode lasting at least three minutes — not a click, and never AFK time.

    Attribution is typed, so not every productive session that follows gets credited to a nudge.

    DIRECT AMBIENT NONE
    1. 01INTERVENTION
    2. 02DISPLAYED → SEEN
    3. 03USER ACTION
    4. 04SUBSEQUENT ACTIVITY
    5. 05RECOVERY WINDOW
    6. 06OUTCOME · RECOVERED / NOT_RECOVERED / INDETERMINATE

    SMALL SAMPLES ARE GUARDED

    1 show · 1 recovery → “Not enough data” not 100% effective

    Test interventions never contribute to effectiveness metrics. Noema does not claim that an intervention improves productivity — it reports what it measured.

    MEME CENTER

    Assets are not responses, and responses are not interventions

    The Meme Center manages a local asset library and the curated response library that references it. It is asset and response management — not the intervention engine.

    Dataset sentiment labels are preserved verbatim as metadata and are never reinterpreted as behavioral meaning. No dataset images are committed to the repository.

    1. DATASET ROWS6,992
    2. VALID ASSETS INGESTED6,991
    3. INVALID · REPORTED, NOT HIDDEN1
    4. CANDIDATES SENT TO MODEL≤ 20

    Retrieval is local and bounded — the model ranks a shortlist, never the whole corpus. Invalid asset IDs returned by the model are rejected, and disabled assets cannot be delivered.

    ASSET→ RETRIEVAL→ RANKING→ RESPONSE→ INTERVENTION

    PRIVACY IS ARCHITECTURAL

    Filtering happens before persistence and before inference

    NEVER COLLECTED OR SENT

    • Keystrokes
    • Screenshots
    • File contents
    • Complete browser history
    • Raw event streams to a model

    FAIL-CLOSED FILTER

    Any filter error blocks by default. URL query parameters are stripped, so search terms never reach stored titles. Private and incognito window titles are always redacted, and password-manager windows are blocked outright.

    The filter only redacts or blocks. It never invents data.

    WHAT STAYS LOCAL

    TELEMETRY · SQLITE · LOGS
    CONFIG · BEHAVIORAL STATE
    INTERVENTION HISTORY
    QUOTA LEDGER · MEME ASSETS

    The daemon API binds to 127.0.0.1:8765 and CORS is restricted to loopback and browser extensions. Hosted inference receives bounded, privacy-filtered evidence only.

    DEVELOPERS

    A daemon, a CLI, and a loopback API

    Install the package, configure a provider, and run the daemon. Everything below is from the repository — the API is local-only, so there is no hosted endpoint and no SDK to sign up for.

    pipeline.py 
    from noema.application.pipeline import NoemaService
from noema.infrastructure.database import SQLiteStore

store = SQLiteStore("noema.db")
service = NoemaService(adapter, store)

service.ingest_telemetry(start="2026-09-04T09:00:00Z")
service.sessionize_stored_events()
service.build_meaningful_sessions()
service.classify_stored_meaningful_sessions()
    powershell 
    # install and start the daemon
pip install .
python -m noema

# one pipeline cycle · inspect telemetry
python -m noema --once
python -m noema telemetry

# deterministic benchmarks · metrics
python -m noema benchmark full --mock
python -m noema metrics summary

# local meme dataset ingestion
python -m noema memes ingest --csv <labels.csv> --dir <images>
python -m noema memes stats

    STATUS · WHAT IS BUILT, WHAT IS NOT

    IMPLEMENTED · V3

    • Native Windows telemetry, presence and AFK
    • Sessionization and semantic episodes
    • Evidence quality and classification
    • Three-valued goal alignment
    • Realtime drift detection
    • Tiered model routing
    • Intervention reasoning and policy gate
    • Typed user actions and break mode
    • Outcome attribution and effectiveness
    • Meme Center, response library, local REST API

    FUTURE WORK · V4 / V5 · NOT IMPLEMENTED

    • Calendar integration, goal hierarchy, deadlines
    • Goal progress, implementation intentions, reminders
    • Longitudinal goal analytics
    • Personalized intervention prediction
    • Adaptive selection and behavioral forecasting
    • Learned response ranking

    WHAT NOEMA DOES NOT CLAIM

    • To perfectly understand intent
    • To classify every activity correctly
    • To know whether an activity was intentional
    • To guarantee an intervention improves productivity
    • To provide a learned intervention policy
    • To predict long-term behavior reliably

    The system is designed to make these limitations explicit rather than hide them.
